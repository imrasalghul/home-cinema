Build a Home Cinema Android TV APK that opens your own website. Fork the project once, enter your server address in GitHub Actions, then download your APK when the build finishes.

  1. Sign in to GitHub and fork the Home Cinema repository. You only need to do this once.
  2. In your fork, open Actions → Build Android TV APK → Run workflow. Enter your website address, including https://, and start the build.
  3. When it completes, open the run summary and download the home-cinema-androidtv artifact.
Fork Home Cinema to build →

Privacy: The address is not committed to your fork, but it is embedded in the APK and can be seen by anyone who obtains it. Never include credentials or secret query parameters. The workflow does not publish your APK; its artifact expires after 7 days.
